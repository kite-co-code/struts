Patterns

Reusable blocks that work on any markup. Each has a small custom-property API, and some have a script.

Patterns are BEM blocks written as Tailwind @utility, so they take variants (md:btn--small) and can be @apply'd. Their knobs follow the custom-property API. Each header comment below is the file's own: it's the API.
